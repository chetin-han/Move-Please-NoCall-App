홈 화면에 설치하고
알림을 켜 주세요

설치해 두면 앱을 닫아도 요청이 오면 알림으로 알려 드려요(안드로이드는 진동 포함). 설치는 무료예요.

  1. 크롬으로 저기요 주소를 열어요
  2. 오른쪽 위 메뉴(⋮) → 홈 화면에 추가 (또는 '앱 설치')
  3. 홈 화면에 생긴 저기요 아이콘으로 열어요
  4. 구글 계정으로 로그인 → 차량 등록 중 알림 허용을 눌러요
회의 중에도 받으려면 폰 설정의 방해금지 모드 예외 앱에 크롬(또는 저기요)을 넣어 두세요.
  1. Safari로 저기요 주소를 열어요 (iOS 16.4 이상)
  2. 공유 버튼(□↑)을 눌러요. 안 보이면 주소창 옆 ⋯ 메뉴 안에 있어요 → 홈 화면에 추가
  3. 홈 화면에 생긴 저기요 아이콘으로 열어요
    Safari에서 연 화면은 알림을 받을 수 없어요
  4. 구글 계정으로 로그인 → 차량 등록 중 알림 허용을 눌러요
집중 모드(방해금지)를 쓰면 설정 → 집중 모드 → 허용된 앱에 저기요를 넣어 두세요.
